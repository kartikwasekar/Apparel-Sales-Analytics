-Apparel Sales Data Analysis

*About the Project:

This project analyzes over 3,000 retail transactions to understand what customers are buying, when they buy it, and how much they spend. The goal is to help clothing brands make better decisions about inventory and marketing.

Tools Used:
Python (Pandas): To clean the raw data, fix missing values, and group customers by age.

SQL: To write advanced queries (like Window Functions) to find the most profitable regions and clothing categories.

Power BI: To build an interactive dashboard that makes the numbers easy to understand.

What I Built:
Data Pipeline: Cleaned messy data and prepared it for a database.

Financial Metrics: Calculated Total Revenue, Average Order Value, and Total Transactions.

Interactive Dashboard: Created visual charts, including a "Seasonal Sizing Heatmap" to show exactly which clothing sizes sell best during different times of the year.


Why This Matters (Business Value)

Helps store managers know exactly how many Small, Medium, or Large items to stock each season.

Shows marketing teams which age groups are spending the most money.

Highlights which product categories (like Outerwear vs. Footwear) bring in the most profit.
